# Aklatan+ — Proposal Document Set

Prepared for engagement with the **National Library of the Philippines (NLP)** and supporting legislative offices.

**Aklatan+** is a *Hybrid Community Library System* that helps public libraries modernize by unifying their physical and digital collections in one platform — designed to **complement and align with** the national library system, not replace it.

## Documents

| Document | Audience | Length | Purpose |
|---|---|---|---|
| [Legislative Brief](./legislative-brief.md) | Senator & staff | 1 page | Why Aklatan+ merits support; the ask |
| [Pilot Brief](./pilot-brief.md) | NLP, LGU partners, decision-makers | 2–3 pages | What the pilot is, who participates, timeline, outcomes |
| [Technical Dossier](./technical-dossier.md) | Technical evaluators | 10–15 pages | Architecture, security, accessibility, offline, operational readiness |

## Reading order

- **Policy / endorsement:** start with the Legislative Brief.
- **Program design:** read the Pilot Brief.
- **Technical due diligence:** read the Technical Dossier.

## Converting to PDF

```bash
pandoc docs/legislative-brief.md  -o legislative-brief.pdf
pandoc docs/pilot-brief.md        -o pilot-brief.pdf
pandoc docs/technical-dossier.md  -o technical-dossier.pdf
```
